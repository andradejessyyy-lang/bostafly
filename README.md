# Bostafly — Landing page

Site officiel de Bostafly. Hébergé sur Hostinger.

## Structure

- `index.html` — Landing page one-page complète (Tailwind via CDN)
- `logo.png` — Logo Bostafly complet (icon + texte)
- `icon-only.png` — Logo Bostafly icon seul (utilisé dans nav + footer)

## Stack

- HTML5 + Tailwind CSS (CDN, pas de build)
- Polices Google Fonts : Plus Jakarta Sans + Inter
- Animations CSS pures + IntersectionObserver

## Déploiement

Push sur `main` → Hostinger pull automatiquement via Git auto-deploy.

## Développement local

Ouvrir simplement `index.html` dans un navigateur. Aucune compilation requise.
